# هنر خودآموزی — The Craft of Self-Teaching

> کسی که توانایی خودآموزی ندارد، آینده‌ای ندارد.<a href='#fn1' id='fn1b'><sup>[۱]</sup></a>

**نویسنده: لی شیائولای — Li Xiaolai (李笑来)**

از دو راهنما و دوست دلسوزم، **Huo Ju (霍炬)**، [@virushuo](https://github.com/virushuo)، و **Hong Qiangning (洪强宁)**، [@hongqn](https://github.com/hongqn)، بابت کمک فراوانشان در نگارش این کتاب صمیمانه سپاسگزارم!

```python
# pseudo-code of selfteaching in Python

def teach_yourself(anything):
    while not create():
        learn()
        practice()
    return teach_yourself(another)

teach_yourself(coding)
```

> **یادداشت مترجم — توضیح تکمیلی:** قطعهٔ بالا pseudo-code است: طرحی برای بیان یک ایده با ظاهر کد، نه برنامه‌ای کامل برای اجرای مستقیم. پیام آن این است که تا رسیدن به توانایی خلق کردن، یاد بگیرید و تمرین کنید؛ سپس همین مسیر را برای موضوعی دیگر ادامه دهید. نام‌ها و کد عیناً حفظ شده‌اند و اجرا نشده‌اند.
