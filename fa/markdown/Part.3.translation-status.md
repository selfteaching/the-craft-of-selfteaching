# گزارش بازبینی و وضعیت ترجمهٔ بخش سوم

## اثر اصلی و اجازهٔ استفاده

نویسندهٔ اثر اصلی **لی شیائولای — Li Xiaolai (李笑来)** است. این ترجمه بر پایهٔ نسخهٔ Markdown چینیِ کتاب **The Craft of Self-Teaching (自学是门手艺)** در [مخزن اصلی selfteaching/the-craft-of-selfteaching](https://github.com/selfteaching/the-craft-of-selfteaching) تهیه شده است. [فصل آغازین بخش سوم، به زبان چینی](../../markdown/Part.3.A.conquering-difficulties.md) در همین نسخهٔ محلی موجود است؛ هر فصل فارسی نیز پیوند منبع چینیِ خودش را دارد. انتساب منابع و نقل‌قول‌ها حفظ شده است.

مجوز اعلام‌شدهٔ اثر اصلی **[CC BY-NC-ND 3.0](https://creativecommons.org/licenses/by-nc-nd/3.0/)** است. این ترجمه فقط برای **مطالعهٔ شخصی و به‌صورت محلی** تهیه شده است؛ اجازهٔ انتشار ترجمه دریافت نشده و مجوز اعلام‌شده نباید به‌عنوان اجازهٔ انتشار ترجمه تلقی شود. نام نویسنده، انتساب منابع و اطلاعات مجوز اصلی باید حفظ شود. تا دریافت اجازهٔ لازم از صاحب حق، انتشار یا ارسال به مخزن، فورک یا branch عمومی مجاز شمرده نمی‌شود. بی‌پاسخ ماندن درخواست اجازه نیز به معنی موافقت نیست. در این مرحله هیچ انتشار، push، deploy یا بارگذاری عمومی انجام نشده است.

## بررسی‌های مستقل و محدودیت‌ها

- در هر ۱۲ جفتِ اصل و ترجمه، **۶۸ بلوک fenced و ۴۶ بلوک خروجیِ تورفته** به‌صورت بایت‌به‌بایت مقایسه شدند و یکسان‌اند؛ delimiterها، فاصله‌ها، commentها، داده‌ها و خروجی‌ها نیز در مقایسهٔ بلوک‌ها لحاظ شدند. خط‌های خالیِ جداکنندهٔ بیرون بلوک‌های خروجی جزو خروجی شمرده نشده‌اند. بلوک‌های grammar نیز حفظ شده‌اند. کد و خروجی اصلی در این مرحله تغییر نکرده است.
- **۵۲ عنوان** خارج از کد در ترجمه‌ها از نظر ترتیب سطح‌ها با اصل یکسان‌اند؛ هر فصل یک عنوان سطح اول دارد و جهش ناموجه در سلسله‌مراتب عنوان‌ها دیده نشد. **۲۸ anchor صریحِ پاورقی و ۲۸ پیوند رفت‌وبرگشتِ مربوط** از نظر وجود مقصد و یکتایی anchorها کنترل شدند. این بررسی متنی است، نه آزمون anchorها در رندر واقعی.
- مقصدهای محلیِ پیوندها و تصاویر در هر ۱۲ فصل، فهرست و همین گزارش از نظر وجود فایل بررسی شدند. ارجاع ناوبریِ فصل C به فصل F به ترجمهٔ موجود متصل شد؛ پیوندهای انتساب به اصل چینی حفظ شدند. متنِ شبیه لینک داخل کد یا خروجی ثبت‌شده، از جمله فهرست چینیِ تولیدشده در فصل D، ناوبری محسوب نشده و دست‌نخورده مانده است.
- در فهرست، دو پیوند قبلی به Notebook فارسیِ ناموجودِ جلد و اثبات مطالعه، با برچسب روشن به Notebook اصلیِ چینیِ موجود هدایت شدند؛ فایل Notebook ساخته یا ویرایش نشد. محتوای پیشین بخش‌های اول و دوم بازنویسی نشده است.
- **خود تصاویر و متن داخل آن‌ها مستقلاً دیده یا بررسی بصری نشده‌اند.** توضیح‌های کنار تصاویر بر متن و زیرنویس منبع تکیه دارند، نه خواندن پیکسل‌های تصویر. وجود فایل تصویر، به معنی ترجمه یا تأیید نوشته‌های آن نیست؛ بازبینی متن مهم داخل تصاویر همچنان باقی است.
- **نمایش راست‌به‌چپ، متن ترکیبی، جدول‌ها، کد و تصاویر در مرورگر یا GitHub رندر و آزمایش نشده است.** کنترل متنیِ قالب‌بندی جای بازبینی بصری را نمی‌گیرد.
- **پیوندهای خارجی و fragmentهای وب به‌صورت زنده آزموده نشده‌اند.** دسترس‌پذیری امروز منابع، رابط ابزارها و دستورهای نصب تأیید نشده است.
- **مثال‌ها به‌طور کامل دوباره اجرا نشده‌اند.** در کارهای قبلیِ B.3 تا B.5 فقط بررسی‌های فنیِ محدود و متمرکز گزارش شده است؛ این بررسی‌ها نه اجرای کامل فصل‌هاست، نه تأیید همهٔ خروجی‌ها. در مرحلهٔ حاضر فقط مقایسهٔ مستقلِ متن کد و خروجی انجام شد. نشانی‌های حافظه، سال 2019، خروجی‌های ناسازگار و خطاهای منبع به‌عنوان دادهٔ ثبت‌شده حفظ شده‌اند. یکسانی با اصل، تضمین صحت فنی یا سازگاری با Python امروزی نیست.
- دامنهٔ ویرایش این مرحله فقط فهرست، همین گزارش، پیوند ناوبریِ C، افزودن پیوند انتساب در B.4 و یادداشت وضعیتِ B.5 است. سایر متن‌های فصل‌ها بازنویسی نشده‌اند؛ فایل‌های اصلی و Notebookها دست‌نخورده مانده‌اند. هیچ فایل موقتِ اعتبارسنجی در خروجی کار باقی نمی‌ماند.

## واژه‌نامهٔ کوتاه مشترک

نام‌های فنی انگلیسی حفظ می‌شوند؛ توضیح‌ها نام مفهوم را جایگزین نمی‌کنند.

| اصطلاح | توضیح سادهٔ مفهوم |
| --- | --- |
| class / object / instance | class الگویی برای ساختن objectهاست؛ instance نمونه‌ای ساخته‌شده از یک class است. خود class هم در Python یک object است. |
| OOP / inheritance / polymorphism | سازمان‌دهی برنامه پیرامون objectها؛ استفاده و گسترش ویژگی‌های class دیگر؛ و رفتارهای متفاوت از راه رابط مشترک. |
| method / attribute / scope | رفتارِ در دسترس از طریق object؛ ویژگیِ وابسته به آن؛ و محدودهٔ دسترسی و جست‌وجوی نام‌ها. |
| encapsulation / property | سازمان‌دادن داده و رفتار در یک واحد؛ و سازوکاری برای کنترل دسترسی به attribute از راه methodها. این‌ها تضمین امنیت یا محرمانگی مطلق نیستند. |
| iterable / iterator | چیزی که می‌توان از آن iterator گرفت؛ و objectای که وضعیت پیمایش را نگه می‌دارد و عضو بعدی را می‌دهد یا StopIteration ایجاد می‌کند. |
| generator / yield | راه تولید تدریجی مقدارها؛ yield اجرا را معلق می‌کند و مقدار را به فراخواننده می‌دهد. |
| decorator / wrapper | سازوکاری برای پوشاندن یا گسترش رفتار؛ و functionِ پوشاننده‌ای که ممکن است جای نام اصلی قرار بگیرد. |
| regex / pattern / engine | زبان توصیف الگوهای متن؛ خود الگو؛ و برنامه‌ای که الگو را تفسیر و اجرا می‌کند. |
| capture / assertion / flag | نگهداری بخش مشخصی از match؛ آزمودن شرط در یک موقعیت؛ و تنظیم رفتار engine. |
| grammar / BNF / EBNF / parser | قاعده‌های ساختار زبان؛ دو شیوهٔ نوشتن این قاعده‌ها؛ و بخشی که ساختار ورودی را طبق آن‌ها تشخیص می‌دهد. |
| glob | الگوهای سادهٔ تطبیق نام فایل؛ با regex یکسان نیست. |
| Framing Effect | اثر شیوهٔ ارائه و قاب‌بندی اطلاعات بر برداشت و قضاوت مخاطب. |

## موارد منبع که در یادداشت‌ها باز مانده‌اند

این فهرست خلاصهٔ موارد مهم است؛ جزئیات و منابعِ توضیح‌های فنی در یادداشتِ فصل مربوط آمده است. حفظ متن اصلی به معنی تأیید این ادعاها نیست.

- **A و F:** توضیح عصبیِ Eureka، تعمیم‌های مربوط به نورون‌های آینه‌ای، سرایت خمیازه و منشأ یادگیری و نسبت‌های عددی، در فصل‌ها منبع پژوهشی ندارند و مستقلاً تأیید نشده‌اند.
- **B.1 و B.2:** متنِ تصویر code-review به بازبینی تصویری نیاز دارد؛ لینک تاریخی Google+ ممکن است در دسترس نباشد. ساده‌سازی‌های self، scope، name mangling و class attribute در یادداشت‌ها توضیح داده شده‌اند. ارجاعِ بدون فراخوانی به self.cease و جایگزین‌شدن property روی خود class در کد اصلی باقی است.
- **B.3:** ناسازگاری خروجی Counter با کد، خلط generator expression و comprehension، زمان اعمال decorator و اسکلت‌های ناقص یا نامعتبر در منبع مشخص شده‌اند؛ کد اصلی اصلاح نشده است. برای نقل‌قول پایانی O’Reilly، منبع اصلی URL و نام نویسندهٔ مقاله را نمی‌دهد؛ مشخصات کتاب‌شناختی کامل همچنان نیازمند بررسی است.
- **B.4:** جدول‌های ساده‌شدهٔ Regex، قواعد Unicode و anchorها، flag ناموجود GLOBAL، lookbehind با طول متغیر، خط سرگردانِ «書評» و خروجی ناقصِ چند فراخوانی در یادداشت‌ها توضیح داده شده‌اند. محدودیت‌های ورودی خالیِ ELIZA و تفاوت engineها باقی‌اند؛ مثال‌های اعتبارسنجی، تضمین جامع‌بودن یا امنیت نیستند.
- **B.5:** angle bracket علامت عمومیِ الزامی‌بودن نیست؛ grammar عدد، grammar واقعیِ literalهای Python نیست؛ parser تاریخی LL(1) وضعیت امروز CPython را نشان نمی‌دهد. تفاوت negation در glob و Regex و غیرهمگانی‌بودن نام eos توضیح داده شده‌اند؛ تصویر مرجع Unix هنوز مستقلاً خوانده نشده است.
- **C و D:** ناسازگاری زمانیِ «هفت سال… یعنی ۲۰۱۷» در روایت Bitcoin نیازمند بررسی است؛ قیاس BTC با سهام دیدگاه نویسنده است، نه تعیین ماهیت حقوقی. نوشته‌های مهم احتمالیِ تصاویر Framing Effect در D هنوز بررسی تصویری و ترجمه نشده‌اند.
- **E:** عنوان منبعِ A Bite of Python با عنوان شناخته‌شدهٔ A Byte of Python فرق دارد؛ Why the lucky stiff نام مستعار است و بیان متفاوتِ منبع جداگانه توضیح داده شده است. انتساب تاریخیِ نقل‌قول کنفوسیوس، تاریخ «۱۹۹۸ تا ۲۰۰۰» و شمول آن بر سمت‌های Xu Jialu مستقلاً تأیید نشده‌اند.
- **G و H:** شمار صفحه‌های Google، نسبت «۹۹ درصد» و تعمیم‌های عددی دربارهٔ والدین در منبع پشتوانهٔ آماری ندارند؛ رابط جست‌وجو و Colab و مشخصات نسخهٔ مقالهٔ پرسش‌پرسیدن تاریخی‌اند و وضعیت امروز آزموده نشده است. حکایت Mac OS توصیهٔ کنارگذاشتن حفاظت امنیتی نیست؛ عادت خوب یا نوع سیستم‌عامل مصونیت در برابر بدافزار را تضمین نمی‌کند.
